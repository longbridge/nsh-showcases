# Directory

Community libraries, components, templates and tools for Native Shell, listed on the [nsh.dev Directory](https://nsh.dev/directory).

Add one folder per project: `directory/<id>/manifest.json`. The `<id>` is the lowercased GitHub repository name (for example `JetSquirrel/nsh-graph` → `nsh-graph`) and must match the manifest `id`; the manifest `name` (the title shown on nsh.dev) is the same repo name. See the root [README.md](../README.md#submit-a-directory-entry) for the fields.
