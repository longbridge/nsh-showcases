# Omasend

Copy, paste, and send to your other devices.

Omasend is a file-sharing app built for Omarchy and a native client for the LocalSend protocol, built with Native Shell. It sends files, folders, screenshots, recordings and text over your local network, to another Omasend or to any LocalSend app, with no account and no cloud upload.

## Everywhere you work

Omasend runs on Linux, macOS and Windows, and on Android and iOS phones, with the same protocol between all of them. Transfers go straight from one device to the other over the local network.
